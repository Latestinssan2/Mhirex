# Mhirex 1.0-beta13

## What's new

- Choose a Reel, YouTube landscape, square, or custom canvas resolution before selecting media; the editor starts with the chosen crop and export height.
- Add Pixabay image and video browsing to the bottom editing toolbar, with popular preview results, optional search, and direct timeline import.
- Add visual template cards for Freeze + skull, Happy Birthday, Noir montage, and Slow this moment.
- Add a Happy Birthday frame with balloons and the bundled birthday melody and chime.
- Place Pixabay contributor credits with imported media.
- Remove the Spotify song link from the editor.
- Use a solid black background with added breathing room around the Android launcher mark.

## Build

- Android version: `1.0-beta13` (version code `17`).
