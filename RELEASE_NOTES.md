# Mhirex 1.0-beta12

## What's new

- Add a top-level Creator Tools menu for Pixabay media, quick templates, Instagram and YouTube watermarks, and local media import.
- Route Pixabay image and video searches through a Vercel server function; the API key stays in Vercel's sensitive environment and is not bundled into the app.
- Add Android's system share sheet after video or audio export so users can choose any compatible installed app.
- Use the supplied dark, black-background Mhirex mark as the Android launcher icon.

## Media rights

Spotify links open Spotify. Mhirex does not download audio from streaming links. Import local media you own or are authorized to use. Review Pixabay source pages and licence terms before using returned media.
