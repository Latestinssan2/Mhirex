# FFmpeg corresponding-source offer

For every Mhirex binary distributed with `com.antonkarpenko:ffmpeg-kit-full-gpl:2.1.0`,
Mhirex maintainers offer the corresponding source for the GPL-covered FFmpegKit
build and the combined Mhirex application under GPL version 3.0.

The source references currently published for the bundled version are:

- [FFmpegKit Full-GPL source, tag `8.0.0-full-gpl`](https://github.com/sk3llo/ffmpeg_kit_flutter/tree/8.0.0-full-gpl)
- [FFmpeg 8.0.0 source, tag `n8.0`](https://github.com/FFmpeg/FFmpeg/tree/n8.0)
- [Mhirex source repository](https://github.com/Latestinssan2/Mhirex), including the release tag's source archive

If any source or build material needed to rebuild the exact bundled Android
libraries is missing from those archives, request it by opening an issue in the
[Mhirex repository](https://github.com/Latestinssan2/Mhirex/issues) with the
release tag and affected ABI. Maintainers will provide the missing corresponding
source and build scripts at no charge for at least three years after distribution
of the applicable binary. This offer applies to `armeabi-v7a`, `arm64-v8a`, and
`x86_64` release APKs.

This offer supplements the publicly linked sources; it does not replace the
license texts in the binary or the source notice in the About screen.
