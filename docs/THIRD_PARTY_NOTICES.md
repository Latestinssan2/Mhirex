# Third-party notices

## FFmpegKit Full-GPL for Android

Mhirex bundles `com.antonkarpenko:ffmpeg-kit-full-gpl:2.1.0`, built with FFmpeg
8.0.0 and GPL-enabled libraries. The Android About screen lists this dependency
and its GPL license in the Open Source Licenses page.

- FFmpegKit source and Android packaging sources: [sk3llo/ffmpeg_kit_flutter, tag `8.0.0-full-gpl`](https://github.com/sk3llo/ffmpeg_kit_flutter/tree/8.0.0-full-gpl)
- FFmpeg 8.0.0 source: [FFmpeg tag `n8.0`](https://github.com/FFmpeg/FFmpeg/tree/n8.0)
- GNU GPL version 3.0 text: [LICENSE](../LICENSE)
- Corresponding-source offer and request instructions: [FFmpeg source offer](FFMPEG_SOURCE_OFFER.md)

The selected Android artifact is distributed under GPL-3.0; its package metadata
also identifies LGPL-3.0 components. Preserve the notices and licenses from the
source projects when rebuilding or redistributing it.
